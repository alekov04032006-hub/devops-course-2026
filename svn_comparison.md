# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка является лёгкой ссылкой на определённый коммит. Поэтому создание и переключение между ветками выполняется быстро и практически не требует дополнительных ресурсов.

В SVN ветвление связано с операциями в централизованном репозитории и обычно требует создания отдельной копии дерева каталогов. Поэтому работа с ветками может быть более затратной.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, если используется удалённый SVN-репозиторий. SVN является централизованной системой контроля версий, поэтому для выполнения коммита необходимо подключение к центральному репозиторию.

В Git коммит можно создавать локально без интернета, потому что репозиторий находится полностью на компьютере разработчика. Интернет нужен, например, для отправки изменений на GitHub.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может быть удобен в проектах, где требуется централизованный контроль доступа и единое хранилище исходного кода. Также SVN может использоваться в существующих корпоративных проектах, которые уже построены на этой системе и имеют настроенную инфраструктуру.

Таким образом, выбор между Git и SVN зависит от требований проекта, его инфраструктуры и организации командной работы.
