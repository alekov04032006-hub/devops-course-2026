# Git в VS Code

## Что удобно

1. Можно видеть изменения файлов прямо в Source Control.
2. Можно просматривать Diff без использования терминала.
3. Можно выполнять commit через графический интерфейс.

## Что удобнее в терминале

В терминале удобнее быстро выполнять несколько Git-команд подряд и полностью контролировать работу с ветками и коммитами.
